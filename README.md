## Sobre el proyecto

CV web personal desarrollado con HTML, CSS y JavaScript puro. Diseño oscuro de alta gama con estética chrome, diamantes animados y tipografía editorial. Totalmente responsive para móvil, tablet y escritorio.

## Vista previa

```
✦ Hero con nombre gótico animado
✦ Diamantes flotando en cada sección
✦ Navegación con menú hamburguesa en móvil
✦ Scroll reveal en todas las secciones
✦ Efectos chrome y sparkles en el fondo
```
